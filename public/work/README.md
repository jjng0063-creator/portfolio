# Project images

Drop project screenshots here and reference them from `portfolioData.ts` as
`/work/<filename>`, e.g. `image: '/work/project-one.png'`.

- **16:9 crops best.** The card is aspect-locked, and the image is anchored to
  the top, so lead with the part worth seeing.
- **Around 1600×900** is plenty. Anything larger is wasted bytes.
- **A real screenshot of the running app** beats a logo or an abstract graphic.
- Always set `imageAlt` alongside it, describing what the screenshot shows.
